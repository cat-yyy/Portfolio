ヒートマップWebアプリ

September 22, 2025

—

概要

開発中の Android アプリから送信される GPS 情報やタイムスタンプを収集し、 Railway 上の Web アプリサーバと MySQL データベースを利用して保存。 そのデータを Web アプリ上で取得し、Google Maps JavaScript API を用いて ヒートマップ表示 するフルスタック Web アプリを構築しました。

アプリURL http://heatmapwebapp-production.up.railway.app

使用技術

  • バックエンド: Python (FastAPI)
  • フロントエンド: HTML, CSS, JavaScript
  • データベース: MySQL
  • インフラ: Railway (Web サーバ + DB サーバ)
  • API: Google Maps JavaScript API

アプリケーションの機能と特徴

  • データ収集と処理:
    開発中のAndroidアプリから、特定の属性（例：ユーザーの活動タイプ、時間帯など）と紐づいたGPS情報（緯度・経度）とタイムスタンプをHTTPリクエスト経由で受信します。 Pythonでこれらのリクエストを受け、Railway上のDBに保存します。

  • データの可視化:
    フロントエンドからのリクエストに基づき、バックエンドがデータベースから関連データを取得します。
    取得したデータをGoogle Maps JavaScript APIが要求するJSONフォーマットに変換し、フロントエンドに送信します。
    JavaScriptがこのデータを受け取り、データの密度や属性にヒートマップを動的に描画します。
    この機能により、データの集中している場所や傾向を一目で把握できます。
    また、各時間帯における属性の数などを一目で理解できるように、グラフで描画します。

  • フルスタック開発:
    DBの構築、バックエンド、フロントエンドの開発の全工程を一人で担当しました。

応用例

開発中の交通量調査アプリで、車両や人の属性に応じたデータの可視化を行う。
画像認識のAPIを使用して、防犯カメラなどから得られる属性に応じたデータを地図上に可視化。
